# Test Reports Directory

This directory stores Playwright test logs, execution summaries, and visual artifact evidence (screenshots, traces, failure captures).

## Structure
- `TEST_REPORTS/evidence/`: Screenshots and media captured during browser automation tests.
- `TEST_REPORTS/runs/`: Playwright execution run summaries and JSON reports.

## Standards
- Every completed milestone must have verifiable test results stored or referenced here.
- Any regression or failed test must include a failure screenshot and console error capture in `BUG_TRACKER.md`.
